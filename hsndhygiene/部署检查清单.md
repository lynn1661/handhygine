
### 2. 权限检查
```bash
# 确保脚本可执行
chmod +x 导入镜像.sh 启动服务.sh
```

### 3. 系统要求
- Docker Engine 20.0+
- docker-compose 1.29+
- 至少4GB可用内存
- 至少8GB可用磁盘空间

## 🚀 快速部署步骤

1. **导入镜像**
   ```bash
   ./导入镜像.sh
   ```

2. **启动服务**
   ```bash
   ./启动服务.sh
   ```

3. **验证部署**
   ```bash
   # 检查服务状态
   docker-compose ps
   
   # 测试接口
   curl http://localhost:3001/health
   curl -I http://localhost:8081
   ```

4. **访问应用**
   - 主应用: http://localhost:8081
   - 后端API: http://localhost:3001
   - AI服务: http://localhost:9501
